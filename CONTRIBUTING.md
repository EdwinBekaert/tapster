# Contributing

Tapster does not accept outside contributions. Pull requests from outside the project will be
closed without review, however good they are.

The reason is the license: Tapster is noncommercial, and its licensor keeps the right to
license it commercially. Accepting contributions would make every contributor a co-owner of
that right.

What is welcome:

- **Bug reports and questions** as GitHub issues.
- **Security vulnerabilities** reported privately, as described in [SECURITY.md](SECURITY.md).
