# 0013. PolyForm Noncommercial 1.0.0

Date: 2026-10-21 · Status: Accepted

## Context
Commercial use of Tapster is not allowed.

## Decision
- Tapster is licensed under PolyForm Noncommercial 1.0.0, with a `Required Notice` line naming the licensor.

## Consequences
- Personal, research, educational, charitable and government use are allowed; commercial use needs a separate license from the licensor.
- Tapster is source-available, not open source in the OSI sense; GitHub shows the license as "Other".
- Outside contributions are not accepted (see [CONTRIBUTING.md](../../CONTRIBUTING.md)): each contributor would co-own the right to license commercially. Bug reports and private vulnerability reports are welcome.

## Alternatives considered
- **MIT, Apache-2.0:** allow commercial use.
- **AGPL-3.0:** allows commercial use if the source is shared.
- **CC BY-NC:** not written for software.
- **Accept contributions under a contributor license agreement:** keeps the commercial right with the licensor, but adds a process this project does not need.
